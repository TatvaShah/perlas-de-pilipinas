# Perlas de Pilipinas

A mobile first demo site for Perlas de Pilipinas, a Filipino restaurant in Scarborough, prepared as a prospect sample by ClaudAura IT Solutions.

The copy, hours, prices, reviews, photos, and reels come from the restaurant's own Instagram, Uber Eats menu, DoorDash listing, and public map data. Nothing on the page is invented.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The site deploys on Vercel with no required environment variables.
